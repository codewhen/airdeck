Download AirDeck PC installers from [Releases](https://github.com/codewhen/airdeck/releases).

## macOS

[Download AirDeck PC 1.5.0](https://github.com/codewhen/airdeck/releases/download/v1.5.0/AirDeck-PC-1.5.0.dmg)

Supports Apple Silicon and Intel Macs running macOS 12 or later. Open the DMG and drag AirDeck PC into Applications.

The current macOS build is ad hoc signed and is not Developer ID signed or notarized. See the release notes for first-launch guidance and SHA-256 checksums.
